# Profile display preferences

Daily supportive phrases are on by default. «Мотиваційна фраза щодня» in profile editing can disable them for that person; the time-based named greeting stays visible. New people use the default and do not inherit another person's disabled setting. Demo mode uses its generic example greeting.

The optional boolean is backward-compatible with the local v1 profile directory. Names/preferences update immediately in the current view and other tabs. Only switching the active person reloads the app and changes the fixed database identity; editing display metadata no longer reloads another tab's in-progress work.

These preferences, like the current local profile directory, are not remote identity, caregiver permissions or a whole-family backup format.
