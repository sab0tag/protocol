## Що це означає для довідника (крок 2)

- **Торгова назва є** — ВЕЛИКИМИ літерами («НУРОФЄН»); для показу — з великої.
- **МНН — латиницею** (`Ibuprofen`, `Levothyroxine sodium`): пошук «ibuprofen» / «nurofen» працює по ньому й транслітерації назви.
  Українська назва речовини — у «Склад (діючі)» у родовому відмінку («містить ібупрофену 200 мг»): звідти — пошук «ібупрофен».
- **Окремої колонки дозування немає.** Беремо `по N мг|мкг|г|МО|мл|%` із «Форми випуску» (87 %); решта — без дози.
  Доза в довіднику — лише щоб розрізнити упаковки; у план вона **ніколи не підставляється**, її вводить людина з призначення.
- **Дублі за МНН** — по латинському МНН; для «Comb drug» — по набору речовин зі «Складу» (інакше всі комбіновані були б «однією речовиною»).
- **Код АТС** — є у 81 %, достатньо для групування; не обов’язковий.
- **Державний формуляр** не потрібен: потрібні поля є в реєстрі.

Індекс будує `scripts/build-meds-index.mjs` (раз на квартал, з нового файлу) у `public/meds-index.json` — на пристрої, без синхронізації.
