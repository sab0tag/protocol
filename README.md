# Протокол

Особистий веб-застосунок (PWA): перетворює план лікаря на щоденні дії — їжа, ліки, вода, тренування, самопочуття.
**Лікар вирішує, застосунок допомагає виконати.** Нічого не діагностує й не призначає.

ТЗ і прийняті рішення — [SPEC.md](SPEC.md). Етапи **M1–M4** готові. Працює на https://protocol.beyondthesignal.to (Vercel, оновлюється з кожним push у `main`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, з телефона — за IP комп'ютера в тій самій мережі
npm test           # модульні тести (Vitest)
npm run build      # перевірка типів + збірка в dist/ (PWA, працює офлайн)
```

## Дані й приватність

- Усе зберігається лише на пристрої (IndexedDB). Жодних запитів назовні, навіть шрифт — усередині збірки.
- Особистий план: створіть `src/data/seed.local.ts` (у `.gitignore`) з функцією `localPlan(): Plan` —
  вона підхопиться при першому запуску замість прикладу з `seed.example.ts`.
- Репозиторій приватний. Справжні медичні дані в git не потрапляють.

## Структура

```
src/app        маршрути
src/screens    екрани (День, Додати їжу, …)
src/components спільні елементи (навігація, нижній лист)
src/domain     модель даних, розрахунок КБЖУ, (M2) правила перевірки страв
src/data       Dexie, вбудована база продуктів, приклад плану
src/i18n       усі тексти інтерфейсу (українською)
tests/unit     Vitest
```
